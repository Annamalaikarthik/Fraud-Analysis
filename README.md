## Fraud Detection Prediction App

Enter transaction details to predict whether a transaction is fraudulent.

### Transaction Information
The application evaluates transactions using:
- **Transaction Type:** CASH_IN, CASH_OUT, DEBIT, PAYMENT, TRANSFER.
- **Transaction Amount:** Total transaction value.
- **Sender's Old Balance:** Sender's balance before the transaction.
- **Receiver's Old Balance:** Receiver's balance before the transaction.
- **Flagged by System Rule:** Whether the transaction was flagged by the bank's rule-based system.

**Note:** Transactions involving amounts greater than the sender's available balance may indicate unusual activity.

### Fraud Detection Results
The application provides one of two predictions:
- **YES:** Transaction is FRAUDULENT.
- **NO:** Transaction is NOT FRAUDULENT.

### Fraud Probability & Risk Assessment
- **High Risk (≥ 70%):** Recommend blocking or manual review.
- **Medium Risk (≥ 30%):** Recommend manual review.
- **Low Risk (< 30%):** Lower fraud probability.

### Disclaimer
Predictions are generated by a machine-learning model and should support, not replace, human decision-making and manual review.
